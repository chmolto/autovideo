# AutoVídeo

App Android personal para ver vídeos de YouTube en la pantalla de Android Auto con el coche aparcado.

- Se elige el vídeo en el móvil (Brave → Compartir → AutoVídeo) y se reproduce en la pantalla del coche.
- Bloqueo de anuncios propio, sin librerías de terceros (solo AndroidX).
- Uso personal: se instala por ADB, no se publica en Play Store.

Diseño: `docs/2026-11-15-video-android-auto-design.md`.

> Requiere activar **Fuentes desconocidas** en los ajustes de desarrollador de Android Auto.
> Úsala solo con el coche parado.
